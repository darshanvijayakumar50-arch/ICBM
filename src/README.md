# ICBM - Instructions to Run

## 1. Prerequisites
Install uv package manager.

## 2. Set up env
Run UV Sync.
```bash
uv sync
```

## 3. Run the estimator script
Run main.py as

```bash
python -m main [input] [output]
```
or
```bash
python src/main.py [input] [output]
```
or
```bash
python -m src.main [input] [output]
```
or simply
```bash
estimate [input] [output]
```
